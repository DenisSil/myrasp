# myrasp

Приложение на Flutter для просмотра расписания Донского государственного технического университета (ДГТУ). Позволяет выбрать свою группу, найти расписание преподавателя или аудитории и добавлять заметки к занятиям.

Данные загружаются из API `edu.donstu.ru`. Расписание, заметки и настройки сохраняются локально на устройстве.

## Возможности

- Выбор основной учебной группы при первом запуске и её изменение в настройках.
- Поиск групп, преподавателей и аудиторий по названию.
- Просмотр занятий: дисциплина, преподаватель, аудитория, время начала и окончания.
- Выбор даты во встроенном календаре.
- Заметки к занятиям с выбором цвета и отметками в календаре.
- Светлая и тёмная темы.
- Локальное кэширование загруженного расписания.

## Запуск

Понадобятся Flutter SDK, Git и настроенное устройство или эмулятор. Для запуска на Android также необходим Android SDK.

В `pubspec.yaml` указан Dart `>=3.0.3 <4.0.0`, а текущий `pubspec.lock` требует `>=3.2.0-194.0.dev <4.0.0`. Используйте Flutter с совместимой версией Dart; совместимость старых зависимостей с новейшими версиями Flutter отдельно не проверена.

```bash
git clone https://github.com/DenisSil/myrasp.git
cd myrasp
flutter doctor
flutter pub get
flutter run
```

При первом запуске выберите свою группу. Для загрузки списков групп, преподавателей, аудиторий и нового расписания нужен доступ к интернету. Отдельный сервер или API-ключ в текущей реализации не требуются.

**Перед использованием проверьте учебный год:** в [lib/service/api_service.dart](lib/service/api_service.dart) запросы справочников используют значение `2023-2024`. Для другого учебного года нужно изменить параметр `year` в запросах `raspGrouplist`, `raspAudlist` и `raspTeacherlist`, в том числе в методе загрузки групп для настроек.

## Источник данных и кэш

[APIService](lib/service/api_service.dart) обращается к API ДГТУ:

- `api/Rasp` — расписание по идентификатору группы, преподавателя или аудитории и выбранной дате.
- `api/raspGrouplist` — список групп.
- `api/raspTeacherlist` — список преподавателей.
- `api/raspAudlist` — список аудиторий.

[ScheduleService](lib/service/schedule_service.dart) сначала ищет расписание в локальном хранилище. Если данных для выбранной даты нет, сервис запрашивает их у API и сохраняет результат.

У кэша пока нет срока действия или механизма принудительного обновления: сохранённое расписание может отличаться от актуального. Полноценный автономный режим не реализован — справочники при запуске запрашиваются из сети.
